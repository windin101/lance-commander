## Changes made

The original STL was modified for use as a game model: display bases, sprues and spare pieces removed; the mesh simplified (vertex clustering); scaled, turned and fitted to the footprint and height of the MechCommander 2 map object it replaces, standing on the ground; painted by region from the original model's own colours; a stand-in: no freely licensed model of the Slayer exists, so this different aerospace fighter design takes its place, fitted to the Slayer's footprint and stretched per axis (x 1.17, y 0.9, z 0.87); plain landing gear (struts and wheels) added at the original's gear positions, since the model is in flight. The changes are made by `tools/art/stl_hd.py`
in this repository (the settings it used: see `original/hd/slayerp/provenance.json` in the build tree).
